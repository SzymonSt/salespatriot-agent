# Glossary

| Term | Meaning |
|---|---|
| **AQAP** | Allied Quality Assurance Publications — NATO quality requirements used in contracts (2110, 2310, 2210). Not a certificate |
| **AU** | Agencja Uzbrojenia — Polish Armament Agency |
| **AS9100 / EN 9100** | Aerospace and defence quality management standard (US / European naming) |
| **ASAP** | Act in Support of Ammunition Production (EU) |
| **BAAINBw** | German federal office for Bundeswehr equipment procurement |
| **BIP** | Biuletyn Informacji Publicznej — Polish public information bulletin sites |
| **BZP** | Biuletyn Zamówień Publicznych — Polish national notices (on e-Zamówienia) |
| **CAN / CN / PIN** | Contract award notice / contract notice / prior information notice |
| **CEIDG** | Polish register of sole traders |
| **CPV** | Common Procurement Vocabulary — EU category codes ([08](08-cpv-codes.md)) |
| **CUI** | Controlled Unclassified Information (US) — banned in the challenge |
| **Directive 2009/81/EC** | EU defence and security procurement directive; TED `legal-basis=32009L0081` |
| **EDA** | European Defence Agency |
| **EDF** | European Defence Fund — EU funding for collaborative defence R&D |
| **EDIP** | European Defence Industry Programme |
| **eForms** | EU standard notice format on TED, mandatory since 25 Oct 2023 |
| **ePO** | eProcurement Ontology — EU ontology for procurement data |
| **eCertis** | EU tool mapping which certificates prove what in each member state |
| **ESPD / JEDZ** | European Single Procurement Document — standard self-declaration (PL: JEDZ) |
| **GLEIF / LEI** | Global Legal Entity Identifier Foundation / Legal Entity Identifier |
| **GQA** | Government Quality Assurance (STANAG 4107) |
| **ITAR / EAR** | US export control regimes — banned in the challenge |
| **ITT / PQQ / RFQ / RFP** | Invitation to tender / pre-qualification questionnaire / request for quotation / request for proposal |
| **KRS** | Krajowy Rejestr Sądowy — Polish court register of companies (has a free API) |
| **NCAGE** | NATO Commercial and Government Entity code — supplier id needed for NSPA |
| **NIP / REGON** | Polish tax id / statistical id |
| **NSPA** | NATO Support and Procurement Agency |
| **Offset** | Industrial compensation obligations attached to large foreign arms purchases |
| **PKD** | Polish classification of business activities |
| **Pzp** | Prawo zamówień publicznych — Polish public procurement law |
| **Prime** | Prime contractor — main system integrator |
| **SAFE** | Security Action for Europe — EU loan instrument for defence procurement |
| **Source File** | NSPA's register of eligible suppliers |
| **TED** | Tenders Electronic Daily — EU procurement journal |
| **Tier 1/2/3** | Supplier levels below the prime (direct supplier, its suppliers, …) |
| **TFEU Art. 346** | Treaty clause letting states exempt purchases for essential security interests |
| **ZASTRZEŻONE** | Polish "RESTRICTED" classification — never collect such material |
| **Evidence levels** | declared · document_verified · independently_verified · peer_attested · inferred |
