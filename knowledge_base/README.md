# Knowledge base — Build the Arsenal (SalesPatriot Europe Challenge)

Shared context for the team's agents and people. Each file covers one topic and is
short enough to load on its own. Load only what the task needs.

Last updated: 2026-10-30 (hackathon day). Sources: team brainstorm, the challenge
brief PDF, and a fact-check pass done on 2026-10-30.

## Evidence labels used in every file

| Label | Meaning |
|---|---|
| `[VERIFIED 2026-10-30]` | Checked against a primary source or a live API call on that date |
| `[REPORTED]` | From earlier research notes; not re-verified. Do not quote numbers on stage without checking |
| `[OWN KNOWLEDGE]` | Added from general domain knowledge; plausible but verify before relying on it |
| `[HYPOTHESIS]` | Team idea or design proposal, not a fact |
| `[TEAM DECISION]` | Agreed by the team; build against it |

Rule for agents: never present a `[REPORTED]` or `[HYPOTHESIS]` item as fact to a
user or judge. If a fact is missing, say it is missing — do not invent it.
